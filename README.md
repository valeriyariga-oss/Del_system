# Business System Analysis Project
# Система управления службой доставки "DeliveryExpress"

# Описание проекта
Разработка комплексной IT-системы для автоматизации процессов курьерской доставки в условиях роста онлайн-продаж. Система объединяет поставщиков, курьеров, клиентов, диспетчеров и бухгалтерию в едином информационном пространстве.

Сервис доставки создан для оптимизации логистики в период роста онлайн-продаж продуктовых магазинов и заведений общественного питания. Платформа централизует обработку заказов, автоматизируя взаимодействие между поставщиками, курьерами и клиентами. Операторы вручную вводят и унифицируют данные о заказах, полученные из различных источников. Курьеры через мобильное приложение получают доступ к доступным заданиям, могут выбирать и резервировать заказы, а также отслеживать статусы их выполнения. Диспетчеры контролируют работу курьеров и при необходимости корректируют распределение заданий. Администраторы управляют учетными записями сотрудников и правами доступа. Система интегрируется с бухгалтерскими сервисами для автоматизации расчетов: передает данные о заказах для взаиморасчетов с поставщиками и информацию о выполненных доставках для начисления заработной платы курьерам. Финансовая информация отображается в персональных кабинетах курьеров

# Бизнес-контекст
В период локдауна наблюдается резкий рост объемов онлайн-продаж, что создает потребность в эффективной системе управления доставкой мелких партий товаров индивидуальным клиентам.

# Цели проекта
- Автоматизация процесса распределения заказов между курьерами
- Сокращение времени доставки за счет оптимизации логистики
- Обеспечение прозрачности всех этапов доставки для всех участников процесса
- Интеграция с бухгалтерской системой для автоматизации расчетов
